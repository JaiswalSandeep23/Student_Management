# 🎓 Student Record Management System

A **Student Record Management System** built using **Python** and **Tkinter**. This desktop application provides an easy-to-use graphical interface for managing student records, including adding, updating, deleting, searching, and viewing statistics. All records are stored permanently using a JSON file, so your data is preserved even after closing the application.

---

## ✨ Features

* ➕ Add new student records
* ✏️ Update existing student information
* ❌ Delete student records
* 🔍 Search students by name
* 📊 View statistics (Total Students, Average Score, Top Scorer)
* 🏆 Automatic grade calculation
* ✅ Pass/Fail status
* 💾 Permanent data storage using **JSON**
* 🖥️ User-friendly GUI built with **Tkinter**

---

## 🛠️ Technologies Used

* **Python 3**
* **Tkinter** (GUI)
* **JSON** (Data Storage)
* **OS Module** (File Handling)

## 💾 Data Storage

Student records are automatically saved in a file named **`students.json`**.

This means:

* Records remain available after closing the application.
* No manual save operation is required.
* The file is created automatically on first run.

---

## 📖 How to Use

1. Enter the student's name.
2. Enter the exam score.
3. Click **Add** to save the record.
4. Select a student to update or delete their record.
5. Use the search box to find students by name.
6. Click **Statistics** to view the total number of students, average score, and top scorer.
